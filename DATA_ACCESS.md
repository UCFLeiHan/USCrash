# Data access

Full crash data are hosted outside GitHub. Public URLs will be added after upload.

The release has 42 state/DC ZIPs, one metadata ZIP, and one code ZIP. State ZIPs preserve canonical annual CSVs byte-for-byte and are independently extractable. The metadata ZIP contains the dictionary, schema, official source inventory, coverage, mappings and checksums.

Release candidate: 2026-10-18; 65,756,924 records; 511 annual files; 77 fields. 2026 is partial. Read dataset/DATASET_CARD.md for source-specific scope.

CC BY-NC 4.0 applies only to eligible original USCrash contributions, as scoped in DATA_LICENSE.md. Source-record redistribution terms, code license, DOI, and final publication metadata remain pending. Original raw archives and validation backups are stored separately.
