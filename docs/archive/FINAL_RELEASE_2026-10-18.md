# Final dataset status

The final dataset remains in `Unified_MMUCC6/data/crash/`: 65,756,924 records, 511 annual files, 77 columns, 41 states and DC. Code is organized under `code/`; inventories under `manifests/`; documentation under `docs/`; reproduction evidence under `verification/`. See `README.md` and `code/README.md`.
